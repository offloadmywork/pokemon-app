## How It Works

### URL Format

```
https://image.pollinations.ai/prompt/[YOUR_PROMPT]?width=512&height=512&nologo=true&seed=[SEED]
```

### Our Implementation

Each Pokemon gets a customized prompt that includes:

1. **Pokemon Name** - For uniqueness
2. **Type Visuals** - Type-specific appearance keywords
3. **Rarity Styling** - Quality level based on rarity
4. **Art Style** - Pokemon card art, official artwork style
5. **Quality Keywords** - Professional, trending, high quality

## Seed System

Each Pokemon gets a **deterministic seed** based on:
```javascript
seed = batchNumber * 1000 + pokemonIndex
```

This means:
- **Batch 1, Pokemon 0** → seed 1000
- **Batch 1, Pokemon 99** → seed 1099
- **Batch 2, Pokemon 0** → seed 2000
- **Batch 10, Pokemon 99** → seed 10099

**Benefits**:
- Same batch+index = same image (reproducible)
- Re-running a batch generates identical images
- No random variations between runs

## Limitations & Considerations

### Known Limitations
- Image generation may take 2-5 seconds on first load
- Images are cached by Pollinations.ai (faster subsequent loads)
- Prompt length limited to URL length (~2000 characters)
- Image style consistency varies (AI interpretation)

### Best Practices
- ✅ Keep prompts descriptive but concise
- ✅ Use consistent art style keywords across all Pokemon
- ✅ Include type-specific visual keywords
- ✅ Test sample images before generating all 1000
- ✅ Use deterministic seeds for reproducibility

### Troubleshooting

**Images not loading?**
- Check internet connection
- Verify URL encoding is correct
- Try opening URL directly in browser

**Image quality varies?**
- This is normal with AI generation
- Adjust prompt keywords for better consistency
- Add more specific art style keywords

**Want different images?**
- Change the seed value
- Adjust prompt keywords
- Re-generate specific batches
